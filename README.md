# WordRay

WordRay 是 Windows 划词翻译工具：在**任意应用**里选中文字，选区附近即可查看译文，并高亮原文与译文中的对应词语。

> **项目状态：划词翻译、词语对齐、设置页、翻译历史和系统托盘已实现，持续完善实机体验。**
> 设计见 [docs/design.md](docs/design.md) · 实现方案见 [docs/implementation-plan.md](docs/implementation-plan.md) · 运行与验收见 [docs/run.md](docs/run.md)

## 设计要点

- **目标形态：选中即弹**，不占用全局热键，不占用 `Ctrl+A`
- 鼠标划选后显示翻译浮标，也支持 `Ctrl + Alt + T` 等全局热键
- **Tauri 2 + Rust + React**，复用系统 WebView2，产物目标 5 MB 量级
- 取词链自主实现：UI Automation 与剪贴板兜底
- 捕获层将跑在**可重建的 helper 子进程**中，第三方 UIA/OLE 卡死不会拖住主进程（阶段 3）
- API Key 使用 Windows DPAPI 本地加密，支持设置页与环境变量
- 关闭翻译面板后驻留系统托盘，单击图标恢复面板，右键可打开设置或退出
- 设置按钮右侧可打开翻译历史：自动保存最新 50 条成功完成的原文和译文，新记录在前，超过上限删除最早记录
- 历史使用 Windows DPAPI 加密后保存到本地 `history.dpapi`，重启后仍可查看；支持复制译文或在面板中查看保存内容，不重新请求翻译

## 技术栈

| 层 | 选型 |
| --- | --- |
| 桌面框架 | Tauri 2 |
| 后端 | Rust 2021、`windows-rs`（SendInput / 前台窗口类名）、`arboard`（剪贴板文本）、`reqwest` + `tokio`（SSE 流式） |
| 前端 | React 19、TypeScript、Vite |
| 密钥存储 | Windows DPAPI 加密配置、环境变量 |
| 翻译历史 | Windows DPAPI 本地加密，保留最新 50 条成功翻译 |
